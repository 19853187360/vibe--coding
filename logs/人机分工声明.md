# 人机分工声明（Research Package 九件套之八 · 模板）

## 分工原则
AI 承担执行与整理，人负责核验与判断。所有 AI 产出在进入下一环节前须经人工复核。

## 各环节分工

| 环节 | 智能体做什么 | 人做什么 | 人工复核方式 |
|---|---|---|---|
| 选题备案 | 起草六字段内容 | 定稿、提交、截图 | 团队讨论确认 |
| 文献检索 | 检索策略与候选清单 | 逐条点开原文核验存在性 | lit_check.xlsx 核验人签名 |
| 数据获取 | AkShare 取数脚本执行 | 核对字段口径、记录采集时间 | 抽1家手算对照(康美600518) |
| 处罚名单 | 网络检索整理候选 | 逐条打开处罚决定书原文 | 补 fraud_year_start + source_url |
| MD&A 抽取 | pdfplumber 批量抽取 | 每10份抽查1份 | 防目录页/乱码 |
| LLM 打分 | 固定量表批量打分 | 20条人工打分复核 | 一致率≥80% |
| 建模实验 | 训练模型、输出结果表 | 核对结果可复现、参数留档 | 一键复现自测 |
| 论文写作 | 按模板生成初稿 | 逐节修改、数字互校 | 每个数字指认到 results/*.csv |
| 审稿 | 独立Reviewer审稿 | 逐条处置审稿意见 | 修改记录留痕 |

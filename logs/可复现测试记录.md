## 复现说明

1. **数据随包提供**：`data/raw/`（325 个财报 CSV，36MB）与 `data/mdas/`（144 个 MD&A 文本）已随 Research Package 提供，无需联网即可完成步骤②—⑤。
2. **步骤③ 需要 API key**：大模型打分需自备 DeepSeek（或其他 OpenAI 兼容服务）key 并设置环境变量 `LLM_API_KEY`/`LLM_BASE_URL`/`LLM_MODEL`；或直接使用已随包提供的 `logs/llm_scores.jsonl` 跳过打分。
3. **年报 PDF**（`pdfs/`，431MB）为 MD&A 文本的原始来源，因体积较大不随 git 仓库分发，可从巨潮资讯网按 `code` 与年度重新下载（见 `code/download_pdfs.py`）；MD&A 抽取结果已固化在 `data/mdas/`，不影响复现。
4. **随机性说明**：LightGBM 含少量随机性（random_state 已固定为 42），逻辑回归完全确定；论文所有数字均可在 `results/` 下对应指认。

# 实验结果汇总（截至 2026-11-17 晚 · D4 完成）

## 主结果（随机划分 random_state=42, stratify, class_weight=balanced）

| 设定 | AUC | 召回率 | 误报率 |
|---|---|---|---|
| 基线：LogReg 仅财务 | 0.765 | 0.556 | 0.167 |
| 改进：LGBM 财务+文本 | 0.951 | 0.889 | 0.000 |
| **文本增益** | **+0.186** | +0.333 | −0.167 |

## 消融实验（同模型 LGBM，同切分同超参——排除换模型混杂）

| 设定 | AUC |
|---|---|
| 仅财务 | 0.673 |
| 仅文本 | 0.957 |
| 财务+文本 | 0.920 |
| LogReg 仅财务 | 0.765 |
| LogReg 财务+文本 | 0.864 |

- 同模型消融增益：+0.247（0.673→0.920）
- 跨模型一致性：LogReg 也 +0.099——增益不是单一模型的"口癖"
- 突出发现：**仅文本（0.957）的判别力高于仅财务（0.673）**

## 前置性检验（t-1 期信号预测 t 期曝光——回应"事后回声"质疑）

| 设定 | AUC |
|---|---|
| t-1 全特征（LogReg, 随机划分） | 0.776 |
| t-1 全特征（LGBM, 随机划分） | 0.576 |
| t-1 全特征（年度划分） | 0.55–0.64（弱，如实报告） |
| **纯文本 t 期（LogReg）** | **0.688** |
| **纯文本 t-1 期（LogReg）** | **0.688** |

- 关键结论：**文本信号的事前判别力与当期完全一致（0.688=0.688）**——文本不是事后回声；
  年度外推口径下证据较弱（样本小），论文如实报告为"混合性证据"。

## 失败案例（改进模型）

| 类型 | 公司 | 核心发现 |
|---|---|---|
| 假阴性 | 獐子岛 2016 | 成本端造假，M-score 不敏感；监管关注期语气谨慎（三维全5分） |
| 假阴性 | 紫晶存储 2019 | "职业化文书"：风险披露充分具体（risk=8）、表述不空泛（vague=3） |
| 假阳性 | 国瓷材料 2016 | 正常高成长公司自信语气+低风险披露，与舞弊画像重叠 |
